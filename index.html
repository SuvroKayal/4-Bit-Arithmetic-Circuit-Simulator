1. Master 4-Bit Arithmetic Circuit (Multiplexer + Ripple Carry Adder)

Purpose: Serves as the central arithmetic processing core of the project. It implements a common adder architecture that calculates Total = A + Y + Cin, where four multiplexers select the second operand Y and carry logic selects Cin based on two control lines S1 and S0.

Step-by-Step Signal Propagation

  1. 1
    Control Line Decoding: Binary control lines S1 and S0 are delivered to the four multiplexers and the carry-in generator.
  2. 2
    Operand Y Selection: Each 4:1 multiplexer selects input: B for Addition (00), B̅ (1's complement) for Subtraction (01), 0000 for Increment (10), or 1111 for Decrement (11).
  3. 3
    Carry-In Activation: Cin is asserted to 1 for Subtraction (completing two's complement B̅ + 1) and for Increment (+ 1); it is 0 for Addition and Decrement.
  4. 4
    Ripple Carry Computation: Stage 0 adds A0 + Y0 + Cin producing sum S0 and carry C1. Carry ripples sequentially through stages 1, 2, and 3.
  5. 5
    Final Output Assembly: Generates the 4-bit binary result vector S[3:0] and final carry output Cout.

Boolean & Arithmetic Equations

General Arithmetic Equation
Total = A + Y + Cin
Where A is the 4-bit first operand, Y is the MUX output, and Cin is the initial carry.
Subtraction via Two's Complement
A - B = A + B̅ + 1
B̅ is obtained by bitwise NOT (1's complement); adding Cin=1 completes the two's complement.

2. 4-Bit Ripple Carry Adder (RCA)

Purpose: Computes the parallel addition of two 4-bit binary numbers by cascading four individual 1-bit Full Adders in series. The carry-out (Cout) of each stage is wired directly to the carry-in (Cin) of the next most significant stage.

Step-by-Step Carry Propagation Flow

  1. FA0
    Stage 0 (LSB): Takes input bits A0, B0, and external Cin. Computes S0 and generates carry C1.
  2. FA1
    Stage 1 (Bit 1): Cannot finalize its outputs until C1 arrives from FA0. Computes S1 and generates carry C2.
  3. FA2
    Stage 2 (Bit 2): Takes A2, B2, and incoming carry C2. Computes sum S2 and carry C3.
  4. FA3
    Stage 3 (MSB): Takes A3, B3, and incoming carry C3. Generates final sum bit S3 and the circuit's final Cout.

Recursive Stage Equations

Sum at Stage i (for i = 0, 1, 2, 3)
Si = Ai ⊕ Bi ⊕ Ci
Carry at Stage i+1 (Ripple Carry)
C(i+1) = (Ai · Bi) + (Ci · (Ai ⊕ Bi))
Where C0 = Cin, and C4 = Final Carry Out (Cout).
Propagation Delay Characteristic
Total Delay = 4 × t_adder
In hardware, each stage introduces gate delay as the carry ripples from LSB to MSB.

3. 1-Bit Full Adder (Constructed from 2 Half Adders & 1 OR Gate)

Purpose: Adds three 1-bit binary inputs (A, B, and carry input Cin) and produces two 1-bit outputs: Sum and Cout. This is the fundamental building block of all multi-bit adders.

Step-by-Step Internal Signal Path

  1. HA1
    Half Adder 1 (Inputs A & B): XOR gate 1 computes intermediate sum S1 = A ⊕ B. AND gate 1 computes intermediate carry C1 = A · B.
  2. HA2
    Half Adder 2 (Inputs S1 & Cin): XOR gate 2 computes the final sum Sum = S1 ⊕ Cin = A ⊕ B ⊕ Cin. AND gate 2 computes carry generation C2 = S1 · Cin.
  3. OR
    OR Gate (Combining C1 & C2): Combines the two carry conditions to generate Cout = C1 + C2. Since C1 and C2 are mutually exclusive (cannot both be 1 simultaneously), an OR gate correctly outputs carry.

Boolean Expressions

Sum Equation
Sum = A ⊕ B ⊕ Cin
True when an odd number of inputs are 1 (parity function).
Carry-Out Equation
Cout = (A · B) + (Cin · (A ⊕ B))
Also expressed in standard SOP form as Cout = AB + BCin + ACin.

4. 1-Bit Half Adder (HA)

Purpose: Adds two single binary digits (A and B) without considering a carry-in from a prior stage. It serves as the introductory arithmetic circuit in digital electronics and forms half of a Full Adder.

Step-by-Step Operation

  1. 1
    Sum Generation: Inputs A and B enter the 2-input XOR gate. The XOR output produces 1 if and only if one input is 1 and the other is 0 (Sum = A ⊕ B).
  2. 2
    Carry Generation: Simultaneously, inputs A and B branch into a 2-input AND gate. The AND output produces 1 only when both A and B are 1 (Carry = A · B).
  3. 3
    Limitation: Because a Half Adder lacks a third input for incoming carry (Cin), it cannot be cascaded directly to perform multi-bit addition beyond the least significant bit (LSB).

Boolean Expressions

Sum Output
Sum = A ⊕ B = A'B + AB'
Carry Output
Carry = A · B

5. Multiplexer Stage & Carry-In Generation Logic

Purpose: Controls which operand is supplied to the second input of the 4-bit Full Adder. Based on the selection lines S1 and S0, it passes B, the 1's complement B̅, all zeros (0000), or all ones (1111), while configuring Cin appropriately.

Operational Mechanics

  1. 00
    Addition (S1=0, S0=0): MUX channels select D0 = B. Carry logic sets Cin = 0. Equation becomes A + B + 0 = A + B.
  2. 01
    Subtraction (S1=0, S0=1): MUX channels select D1 = B̅ (inverted via NOT gates). Carry logic asserts Cin = 1. Equation becomes A + B̅ + 1 = A - B in two's complement.
  3. 10
    Increment (S1=1, S0=0): MUX channels select D2 = 0 (GND). Carry logic asserts Cin = 1. Equation becomes A + 0 + 1 = A + 1.
  4. 11
    Decrement (S1=1, S0=1): MUX channels select D3 = 1 (Vcc), producing 1111₂ (-1 in 4-bit two's complement). Carry logic sets Cin = 0. Equation becomes A + 15 + 0 = A - 1.

Multiplexer Output Equations

Multiplexer Output for Bit i (Yi)
Yi = (S1' · S0' · Bi) + (S1' · S0 · Bi') + (S1 · S0 · 1)
When S1=1 and S0=0, D2=0, so the term evaluates to 0.
Carry-In Logic Equation
Cin = S1 ⊕ S0 = (S1' · S0) + (S1 · S0')
Cin is 1 whenever S1 and S0 are different (for Subtraction and Increment).

6. Digital Logic Gate Primitives (AND, OR, XOR, NOT)

Purpose: The fundamental atomic components of digital electronics. In this project: XOR computes bit sums, AND computes carry generation, OR merges carry pathways, and NOT produces 1's complement negation for subtraction.

AND Gate

Y = A · B

Output is 1 ONLY if both A AND B are 1. Used in carry generation.

OR Gate

Y = A + B

Output is 1 if AT LEAST ONE input is 1. Used in carry combination.

XOR Gate

Y = A ⊕ B

Output is 1 when inputs are DIFFERENT. Used for binary addition modulo 2.

NOT Gate

Y = A' (Inverter)

Inverts logic state (0→1, 1→0). Used for 1's complement subtraction.

Digital Electronics & Computer Architecture Theory

Prepared for viva examination and conceptual evaluation in 3rd Semester B.Tech Computer Science & Engineering.

01

Binary Number System & 4-Bit Nibbles

A bit (binary digit) is the fundamental unit of digital information, holding either 0 or 1. A grouping of 4 bits is technically termed a nibble.
• Unsigned Range: 0000₂ to 1111₂ (0 to 15 in decimal)
• Signed (2's Complement): 1000₂ to 0111₂ (-8 to +7 in decimal)
In CPU architectures, 4-bit ALUs formed the historical basis for microprocessors (such as the Intel 4004) before scaling to 8, 16, 32, and 64 bits.
02

Half Adder vs Full Adder

The key distinction lies in the handling of carry inputs:
• Half Adder: Accepts 2 inputs (A, B). Generates Sum and Carry. Cannot accept an incoming carry.
• Full Adder: Accepts 3 inputs (A, B, Cin). Generates Sum and Cout. Cascades into n-bit parallel adders.
A Full Adder is architecturally constructed using two Half Adders and one OR gate: HA1 combines A and B; HA2 adds Cin to that partial sum; the OR gate merges both carry generation conditions.
03

Two's Complement Subtraction

Modern computers do not build a separate hardware subtractor. Instead, subtraction is converted into addition using two's complement:
A - B = A + (-B) = A + (B̅ + 1)
By bitwise inverting operand B (1's complement) and injecting a 1 through the adder's Carry-In (Cin=1), the adder hardware executes subtraction natively!
04

Carry vs. Borrow Interpretation

In two's complement subtraction using an adder:
• Cout = 1: No borrow was required (A ≥ B). The positive result is directly in binary.
• Cout = 0: A borrow occurred (A < B). The result is negative and is formatted in 2's complement.
This inverse carry relationship is fundamental to how CPU status register flags (e.g., the C flag in x86 or ARM) interpret subtraction.
05

Carry Propagation & Ripple Delay

In a Ripple Carry Adder (RCA), each stage must wait for the carry bit to ripple through from the preceding lower-order stage:
Total Delay = N × t_stage
While RCA requires minimal hardware (linear gate count O(N)), carry ripple introduces a latency trade-off. For higher-performance CPUs, Carry-Lookahead Adders (CLA) predict carries in parallel to minimize latency.
06

Role in Modern CPU ALUs

The Arithmetic Logic Unit (ALU) of a central processing unit uses control signals from the CPU Instruction Decoder to select arithmetic and logic operations.
Opcode → Control Lines (S1, S0) → Multiplexer → Adder Matrix
This project faithfully simulates the core arithmetic sub-unit of a classic M. Morris Mano computer architecture model.
